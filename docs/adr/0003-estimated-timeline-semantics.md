# ADR 0003：估算时序、动作重叠与取消语义

- 状态：已接受；Phase 2 待实施
- 日期：2026-08-10

## 决策

### 估算时序

Phase 2 不要求逐动作实测命中帧和持续时间。编译器按伤害段数与集中配置的每段估算时长推导动作区间：多段命中在区间内均匀分布，单段动作在动作结束时命中。所有推导值标记为 `estimated`，未来可由单个动作的实测值覆盖。

### 动作重叠

动作数据需显式表达执行方式，不根据名称或伤害类型推断：

- 前台动作占用当前角色；
- 召唤型声骸等启动后独立执行的持久动作可与后续角色动作重叠；
- 协同攻击由其触发条件派生，不占用前台动作；
- 角色技能施放途中切换角色不打断原动作；原动作在后台保留后续命中与效果，并与新角色动作重叠。

召唤型持久动作、协同攻击和因切换角色转入后台的原动作可重叠；同一当前角色的普通前台动作重叠应产生冲突诊断。

### 闪避取消

用户在时间轴放置闪避动作。闪避取消当前前台动作，编译器不再生成取消时刻及之后的命中、结束时 Buff 和后续资源事件。动作开始时已经获得的 Buff、已扣除或获得的资源及其他已结算事件不回滚。

持久动作启动后不会因角色的后续闪避而终止，除非动作数据明确声明可被该方式取消。

### 同时间戳结算

事件按 `(timeMs, priority, sequence)` 稳定排序。一个时间戳内的阶段顺序为：

1. 移除结束时间早于当前时刻的效果。
2. 处理角色切换、闪避取消、动作开始、前置验证与资源消耗。闪避会抑制同时间戳上被取消动作尚未执行的命中。
3. 施加 `action-start` 效果。
4. 对当前时间戳的所有命中使用同一份命中前状态快照计算伤害。
5. 所有命中完成后，再按稳定序号处理 `hit-after` 效果、资源回复和其他派生事件。
6. 处理结束时间等于当前时刻的效果到期与动作结束。

Buff 的结束时间包含端点。`action-start` 效果可以影响同时间戳的命中；`hit-after` 效果不影响同时间戳的任何命中，只会影响之后时间戳的事件。

## 后果

- 时间轴 schema 需要动作执行方式、离场持续与取消行为字段。
- 闪避是可编辑动作，取消时刻由闪避事件派生，不在原技能上重复存储。
- 编译器必须在运行模拟前完成重叠合法性、取消截断和事件优先级分组。
- 测试必须覆盖普通动作冲突、三类允许重叠、取消前后的命中/效果/资源、Buff 端点和同时间戳快照。
