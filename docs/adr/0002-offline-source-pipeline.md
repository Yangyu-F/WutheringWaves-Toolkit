# ADR 0002：生产站点使用审核后的离线静态数据

- 状态：提议；待 Phase 0 实施时确认
- 日期：2026-08-08

## 决策

计划中的浏览器应用与 CI 不调用 WIKI 内部服务。数据通过“来源 manifest → candidate → 人工审核 → 版本化静态数据”进入产品。

## 原因

WIKI 的计算相关内容主要存在于富文本，内部载荷不是稳定的公共 API；运行时依赖会损害可复现性、隐私、离线能力和历史版本重算。

## 后果

Phase 0 计划只提交合成 fixture。真实 fetcher 必须在自动化访问许可确认后另行设计，并且同步结果不能自动发布。
