# Phase 2 入口检查

> 检查日期：2026-08-10
> 结论：Phase 1 已达到验收标准；Phase 2 的估算命中时序、动作重叠、闪避取消和同时间戳事件顺序已形成 ADR 0003。

## 已满足

- 3.5 单共鸣者纵向切片已覆盖秧秧、千古洑流、飞廉之猩和啸谷长风。
- 官方中文实体名、技能名、武器效果名、声骸命中动作与合鸣档位已复核。
- 基础伤害、防御、抗性、暴击、增伤、易伤、倍率加深与独立乘区已分层实现并有边界测试。
- 动作编译、声明式效果、叠层/过期、声骸词条合法性与金标准结果已有自动化测试。
- 模拟核心与 Vue/Pinia/DOM 解耦，可作为 Worker 和时间轴的基础。

## 已确定的时序简化

1. 不将逐技能真实命中帧与动作时长作为 Phase 2 门槛。
2. 动作持续时间按伤害段数与集中的每段估算时长推导；具体估算系数在 Phase 2 时序 ADR 中集中定义。
3. 多段命中在动作区间内均匀分布；单段动作在动作结束时命中。
4. 所有推导时序标记为 `estimated`，以后可按动作提供实测覆盖，但不要求全量测试。

## 已确定的重叠与取消规则

1. 启动后独立执行的召唤型声骸、协同攻击，以及切换角色后由原角色继续执行的技能可与新角色动作重叠。
2. 用户放置闪避取消当前前台动作；取消后未执行的伤害、Buff 和资源事件被丢弃，动作开始时已结算的效果不回滚。
3. 同时间戳命中共享命中前快照；`hit-after` 效果不影响同时间戳的其他命中，Buff 结束时间包含端点。

## 仍待决策

1. 时间轴交互采用 Pointer Events 自研还是引入拖拽库，以及键盘精确编辑与撤销/重做数据模型。
2. 开始本地持久化前确认 IndexedDB 封装、schema 版本和迁移边界。

## 推荐的下一步

可以进入 Phase 2 实现。先围绕 ADR 0003 扩展动作 schema、估算时序编译和取消/重叠测试，再实现可视化时间轴与 Worker 协议。
