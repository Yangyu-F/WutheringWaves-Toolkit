## 官方命名复核

- 千古洑流的官方具名武器效果为“流涡无垠”，实体数据保留该显示名，稳定 ID 继续使用 `liuwo-wuyin`。
- 飞廉之猩的官方技能正文将两次命中称为“踢击”和“追击”，命中 ID 因此使用 `tiji` 与 `zhuiji`。该声骸技能没有另外的官方专名，展示名继续使用“声骸技能·飞廉之猩”。
- 啸谷长风的官方正文只标记“2件套”和“5件套”，没有额外具名效果；实现不虚构效果专名。

## 注意事项

- BWiki 同时存在旧路径 `角色/秧秧` 与明确的 `共鸣者/秧秧`。前者当前混有“秧秧·玄翎”内容，自动采集不得把两名角色的数据合并。
- WikiWiki 的共鸣者使用日文译名时，交叉核对必须依赖稳定对象映射，不能只按显示名称匹配。
- 简体中文名称保留官方 Wiki 的用字和层级。计算器中的动作显示为“技能分类·官方技能名·动作名”，例如 `共鸣回路·覆声裁羽·重击·风袭`；社区页面的简称只作为检索别名。
- 动作内 `offsetMs` 仍只是稳定命中排序，不属于本次资料数值核对结果。
