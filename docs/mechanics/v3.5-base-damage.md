# 3.5 基础伤害纵向切片

> 状态：Phase 1 已实现；适用游戏版本 3.5
>
> 最近核对：2026-08-10

## 范围

当前实现覆盖“配置 → 动作编译 → 声明式效果状态 → 逐次伤害分解”的完整链路。正式配置只使用 90 级、满技能共鸣者，90 级武器和 +25/最高技能阶五星声骸；秧秧全部造成伤害的动作均使用 Lv.10 倍率。

## 当前公式

单次命中：

```text
攻击力 = (角色满级基础攻击 + 武器满级基础攻击) × (1 + 攻击力%合计) + 固定攻击力合计
最终伤害 = 攻击力 × 技能倍率 × 倍率提升 × 伤害加成 × 伤害加深
         × 暴击乘区 × 其他独立乘区 × 防御乘区 × 抗性乘区
```

防御乘区：

```text
(100 + 共鸣者等级)
────────────────────────────────────────────────────────────────────────
(100 + 共鸣者等级) + (99 + 敌人等级) × (1 - 防御无视% - 防御降低%)
```

抗性乘区：

```text
抗性 < 0       : 1 - 抗性 / 2
0 ≤ 抗性 < 0.8 : 1 - 抗性
抗性 ≥ 0.8     : 1 / (1 + 5 × 抗性)
```

最终抗性先按“敌人基础抗性 - 抗性降低 - 抗性无视”合成。负抗和 0–80% 分支标记为 `cross-checked`；80% 及以上分支在多个社区公式库与独立计算器中一致，标记为 `community-consensus`，仍需 80% 以上游戏内对照样本升级为实测状态。三段公式在 0% 与 80% 边界连续。

特殊完全免疫不是普通的 100% 抗性：普通 100% 抗性按公式仍有 `1/6` 乘区；明确免疫的目标必须由独立机制返回 0，不能编码为 `resistance = 1`。

期望暴击乘区：

```text
1 + 暴击率 × (暴击伤害倍率 - 1)
```

内部全程保留浮点精度，只有展示层舍入。当前公式由金标准测试锁定，但在完成 3.5 游戏内样本反推前仍属于“可审计实现”，不能宣称覆盖所有隐藏取整与特殊乘区。

## 已知限制

- 千古洑流叠层、飞廉之猩追击后 Buff、啸谷长风变奏 Buff、怀悯和共鸣链效果均由动作数据中的声明式触发器施加和过期。
- 倍率提升、伤害加成、伤害加深、独立乘区、防御无视/降低、抗性无视/降低均已拆分；当前纵向配置没有实际提供的乘区保持 `0`，不与其他乘区合并伪造。
- 五星声骸固定 +25、主动技能固定最高阶。主词条按 COST 使用固定 +25 数值，COST 4/3 的固定副主属性攻击分别为 150/100，COST 1 的固定副主属性生命为 2280；每枚声骸最多五条不重复的合法档位副词条。
- 敌人只使用等级和气动抗性，不绑定敌人条目。
- `offsetMs` 仅保证 Phase 1 的稳定命中顺序。真实帧、动作持续时间、取消窗口与可视化时间轴属于 Phase 2，不阻塞本阶段验收。
